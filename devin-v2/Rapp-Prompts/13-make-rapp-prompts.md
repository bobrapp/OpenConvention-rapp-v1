# 13 · Turn a session into Rapp-Prompts

Paste everything below the line into Devin at the end of a build session.

---

**Goal:** Write a step-by-step version of each prompt I gave in this session, in the *Checklist Manifesto* style, and call it Rapp-Prompts.

## Pause point 1 · Gather (READ-DO)
1. List every prompt I gave, in order. Merge follow-ups into the prompt they refine, and skip small talk.
2. For each prompt, note what went wrong or needed rework in this session. Those become **(must)** items. **(must)**

## Pause point 2 · Write (READ-DO)
3. One file per prompt (`Rapp-Prompts/NN-name.md`) containing: goal, what I provide, then pause points with READ-DO steps and a final DO-CONFIRM list.
4. About 5–9 items per pause point, in plain verbs. Mark the killer items with **(must)**.
5. Make each file paste-ready on its own: `[bracketed]` fill-ins with my values as defaults, and a note on which prompts it depends on.
6. Write a `README.md` explaining the style and the run order, with a table linking every prompt to my original words.

## Pause point 3 · Before saying "done" (DO-CONFIRM)
- [ ] No secrets, session IDs or private links in any file.
- [ ] Every prompt from the session is covered.
- [ ] Committed to the working branch and pushed, and sent me the link.
