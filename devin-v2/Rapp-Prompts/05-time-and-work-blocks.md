# 05 · Event time + work calendar

Paste everything below the line into Devin. Requires prompt 01.

**Goal:** Manage my time at the event and my work calendar in one timeline.

## Pause point 1 · Before building (READ-DO)
1. Ask me: connect a real calendar, or use manual work blocks? If no calendar integration is connected, default to manual work blocks plus `.ics` import. Don't pause the whole build on this question. **(must)**

## Pause point 2 · Build (READ-DO)
2. A unified timeline per day with sessions, BoFs, 1:1s and work blocks, each in its own color.
3. Quick-add work block: title, day, start, end.
4. Flag overlapping items as conflicts and highlight free windows.
5. Smart warnings: no lunch break, more than 3 hours without a break, back-to-back sessions in different rooms.
6. `.ics` export (everything, or one item) and `.ics` import, with imported events becoming work blocks.

## Pause point 3 · Before saying "done" (DO-CONFIRM)
- [ ] Created an overlap and the conflict flag appeared. Removed it and the flag cleared.
- [ ] Imported a sample Outlook/Google `.ics` and the blocks appeared on the right days and times.
- [ ] The exported `.ics` uses CRLF line endings and valid DTSTART/DTEND, and opens in Apple and Google Calendar. **(must)**
